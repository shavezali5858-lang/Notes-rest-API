# Notes API

A basic REST API built with Node.js and Express.js for managing notes.

## Features

- Create a note
- Get all notes
- Get a note by ID
- Update a note
- Delete a note
- RESTful API structure

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| POST | `/arouter.post("/",createTask)pi/notes` | Create a new note |
| GET | `/router.get("/",getTask)api/notes` | Get all notes |
| GET | `/router.get("/:id",taskbyID)api/notes/:id` | Get a note by ID |
| PATCH | `/router.patch("/:id",updateTask)api/notes/:id` | Update a note |
| DELETE | `/arouter.delete("/:id",deletetask)pi/notes/:id` | Delete a note |
